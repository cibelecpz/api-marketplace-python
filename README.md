# API Marketplace Python

API REST para gerenciamento de um marketplace, desenvolvida em Python.

## Objetivo

Este projeto foi criado para praticar desenvolvimento backend utilizando Python, banco de dados e APIs REST.

## Funcionalidades

- Cadastro de produtos
- Cadastro de clientes
- Cadastro de pedidos
- Controle de estoque
- Cálculo de lucro
- Cálculo de taxas
- Histórico de pedidos

## Tecnologias

- Python
- FastAPI
- SQLite
- SQLAlchemy
- Pydantic
- Git
- GitHub
